# Data Engineering Practice Exercises

This repository is a clone of the original Data Engineering practice repository created for learning and hands-on skill development.
[Original Repository](https://github.com/danielbeach/data-engineering-practice)

The purpose of this repository is to build practical understanding of common tools and workflows used in Data Engineering.

Topics covered include:

- Python data processing
- Working with file formats
  - CSV
  - JSON
  - Flat files
  - Parquet
- Web scraping
- Data ingestion
- Database schema design
- SQL and PostgreSQL
- Python + PostgreSQL integration
- AWS S3 with Boto3
- PySpark
- Data cleansing and transformation
- DuckDB
- Polars
- Data quality checks
